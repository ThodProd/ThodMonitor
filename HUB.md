# ThodHUB

Самостоятельная программа, устанавливаемая из каталога ThodHUB. Интерфейс мониторинга,
оверлеи и настройки открываются в отдельном окне; хаб создаёт ярлык на рабочем столе.
Манифест пакета: `hub/manifest.json`.

`--thodhub-data <path>` задаёт отдельную папку данных до инициализации программы,
в том числе при запуске через UAC. Хаб остаётся обычным пользовательским процессом.
Без этого аргумента сохраняется самостоятельное поведение программы.

Пакет содержит .NET runtime. Для части датчиков и FPS нужны административные права.
PresentMon не включён: его отсутствие должно отображаться как отсутствие измерения,
а не как выдуманное значение. Установка хабом сама по себе не включает автозапуск.

Автозапуск отключён при запуске через ThodHUB, чтобы версия не оставляла системные записи после удаления. Самостоятельный запуск сохраняет прежнее поведение.
